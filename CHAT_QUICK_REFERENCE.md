# 🚀 Team Chat - Quick Reference Card

## Shortcuts at a Glance

### @ Mentions
| Syntax | Result | Example |
|--------|--------|---------|
| `@username` | Mention teammate | `@Sarah check this out` |
| `@file:name` | Reference file | `See @file:T-800 Specs.pdf` |

### / Commands
| Command | What it does | Example |
|---------|-------------|---------|
| `/help` | Show all commands | `/help` |
| `/invite` | Invite team member | `/invite john@company.com` |
| `/remind` | Set reminder | `/remind Review docs` |
| `/schedule` | Schedule meeting | `/schedule tomorrow 2pm` |
| `/giphy` | Search GIF | `/giphy celebration` |

### ⌨️ Keyboard Shortcuts
- `↑` / `↓` - Navigate suggestions
- `Enter` - Select suggestion
- `Esc` - Close autocomplete
- `?` icon - Toggle help panel

---

## 💡 Pro Tips

1. **Speed Mention**: Type `@` + first letter + Enter
2. **Multiple Tags**: Tag several people in one message
3. **File Quick Ref**: Use `@file:` for instant document links
4. **Command Help**: Type `/help` to see all commands
5. **Keyboard Pro**: Navigate entirely with keyboard
